# uppgift2
Filsystem och terminal

I den här övningen använde jag terminalen för att skapa en kursmapp, en projektmapp och en textfil.

Kommandon jag använde

Jag använde mkdir kurs1 för att skapa kursmappen kurs1. Sedan använde jag cd kurs1 för att gå in i mappen.

Därefter använde jag mkdir projekt för att skapa projektmappen och cd projekt för att gå in i den.

Till sist använde jag touch newFile.txt för att skapa textfilen newFile.txt.
